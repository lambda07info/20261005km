# 出版物から学ぶカンボジア語

## プロジェクト概要

日本語話者向けのカンボジア語学習教材は限られている。

本プロジェクトでは、JW\.orgのカンボジア語出版物で実際に使用されている語彙・表現・文法・構文・文章を分析し、その結果に基づいて、日本語話者向けの体系的なカンボジア語学習教材を作成する。

対象読者は、カンボジア語を学ぶJWの日本語話者とする。

教材を通して、次のことができるようになることを目標とする。

- カンボジア語の語彙・文法・構文を体系的に理解する
- JW出版物で頻繁に使われる表現を理解する
- 語・句・節をどのように組み合わせて文を作るかを理解する
- JW出版物を自力で読解できる力を身につける
- 出版物で使用されている表現を、JWとしての活動に応用できるようにする

文字と発音は本教材の対象外とし、別教材などで基礎を学習済みであることを前提とする。

## 教材の情報源

教材の言語データは、原則としてJWのカンボジア語出版物に限定する。

主な資料：

- 『いつまでも幸せに暮らせます』
- 『ものみの塔』
- 『生活と奉仕 集会ワークブック』（MWB）

必要に応じて、その他のJWカンボジア語出版物も分析対象に含める。

語彙・例文・表現・構文について、JW出版物で使用が確認できないものを教材用として独自に作成しない。

教材で使用する表現については、可能な限り出典を追跡できる状態にする。

## 教材

教材は、大きく次の2つで構成する。

### 教科書

出版物を理解し、自分でもカンボジア語の文を組み立てられるようになるために必要な言語知識を体系的に学ぶ。

主な対象：

- 文法
- 文の型・構文
- 機能語とその用法
- まとまりで使われる表現
- 文をつなぐ表現
- 複文や修飾構造
- 語・句・節の並べ方
- 構文同士の組み合わせ方
- 文中で要素を置ける位置や省略できる要素
- 文章構造
- 出版物読解

個々の文法項目を説明するだけでなく、語・句・節がどのような順序と組み合わせで文を構成するかを明らかにし、カンボジア語の「文の組み立て方」を体系として理解できる教材を目指す。

具体的な学習項目や学習順序は事前に固定せず、出版物の分析結果に基づいて決定する。

### Anki

出版物から抽出した学習項目を反復し、記憶に定着させる。

主な対象：

- 単語
- 複数語からなる表現・チャンク
- 文法・構文パターン
- 出版物で実際に使用されている文・表現

必要に応じて、文の構造や構文のスロットを覚えるためのカードも作成する。

例：

- ある構文の後ろに何を置けるか
- 文中の空欄にどの機能語・構文が入るか
- 複数の構文をどのように組み合わせるか

教科書とAnkiは独立して設計するのではなく、同じ分析結果とLanguage Inventoryを基礎として連携させる。

### 教科書の出力・公開形式

教科書の原稿はMarkdown形式を基本とし、Markdownファイルを教材本文の正本として管理する。

完成したMarkdownからWebサイトを生成して公開する。
Webサイトの生成にはAstroを使用し、教材の章構成、ナビゲーション、検索、目次などを効率よく実装するため、AstroベースのドキュメントフレームワークであるStarlightを第一候補とする。

教材本文とWebサイト固有の表示ロジックは可能な限り分離し、教材本文が特定のフレームワークに強く依存しない構成とする。

原則として通常のMarkdownを使用し、構文表示や文構造表示など、通常のMarkdownでは表現しにくい教材機能に限ってMDXや独自コンポーネントを使用する。

各教材ページには必要に応じてメタデータを持たせ、Language Inventory上の学習項目IDと関連付ける。

これにより、

Language Inventory
→ 教科書
→ Anki

の対応関係を追跡できるようにする。

教材本文とその構造をWebサイトから独立させて管理することで、将来的なPDF、EPUB、印刷物、別のWebシステムなどへの再利用も可能な構成とする。

## 教材の作成方針

最初から既存の外国語教材の体系を当てはめて、「何を教えるか」「どの順番で教えるか」を決めない。

まずJW出版物をコーパスとして分析し、実際に使用されている言語要素を抽出する。

主な分析対象は次の通りとする。

- 語彙と出現頻度
- 複数語からなる頻出表現
- 機能語とその用法
- 文法・構文パターン
- 語や表現の共起関係
- 語・句・節の並び方
- 各構文で使用できる要素
- 文中における構文の位置
- 構文同士の組み合わせ
- 省略や語順変化のパターン
- 文をつなぐ表現
- 複文・修飾構造
- 文章・談話のパターン

特に、単独の文法事項だけでなく、

- どの要素をどの順番で置くことができるか
- 各位置にどの種類の語・句・節を置けるか
- どの構文とどの構文を組み合わせられるか
- 何を省略できるか
- 語順が変わる場合に、意味や情報の焦点がどう変化するか

を分析し、文を組み立てるための構文体系として整理する。

## Language Inventory

出版物の分析結果を、教材作成の基礎データとなるLanguage Inventoryに整理する。

Language Inventoryの構成・各項目の基本データ・教材との関係については、[Language Inventoryの設計](docs/language-inventory.md)を参照する。

Language Inventoryには、必要に応じて次のような情報を持たせる。

- 学習項目
- 種類
  - 語彙
  - 機能語
  - 複数語表現
  - 構文
  - 文をつなぐ表現
  - 文章構造
- 意味・機能
- 構造・パターン
- 構成要素
- 各要素に入れられる語・句・節
- 文中での位置
- 組み合わせ可能な構文
- 省略・語順変化
- 出現頻度
- 使用される文脈
- 難易度
- 前提となる学習項目
- 関連する学習項目
- 出典
- 出版物中の実例

Language Inventoryは、教科書とAnkiの共通の基礎データとして使用する。

## 学習体系の設計

Language Inventory作成後、それぞれの学習項目について、次の観点から学習順序を設計する。

- 出現頻度
- 理解・運用上の重要度
- 難易度
- 他の項目を理解するための前提関係
- 他の構文や表現との組み合わせやすさ
- 出版物読解への寄与
- 実際に文を組み立てる際の有用性

頻度だけで学習順序を決めるのではなく、学習項目同士の依存関係も考慮する。

## 教科書の基本的な学習方法

各学習項目では、可能な限り次の流れを採用する。

1. 出版物中の実例を見る
2. 文や表現を構成要素に分解する
3. 各要素の意味・働きを理解する
4. 使用されている構文や文の型を整理する
5. 各位置に何を置けるかを確認する
6. 他の構文とどのように組み合わせられるかを確認する
7. 別の出版物中の実例で用法を確認する
8. 実際の文章を読解する
9. 必要に応じて、自分で文を組み立てる練習を行う

単に日本語訳を覚えるのではなく、カンボジア語の構造そのものを理解することを重視する。

## 作業工程

基本的な作業工程は次の通りとする。

JW出版物
→ コーパス化
→ 言語分析
→ Language Inventory作成
→ 学習項目・学習順序の設計
→ 教科書作成
→ Anki作成
→ 検証・改善

教材作成後も、分析によって新しい知見が得られた場合はLanguage Inventoryを更新し、その影響を確認した上で教科書・Ankiにも反映する。

## 品質方針

教材の内容は、分析対象となったJW出版物の実際の言語使用を根拠とする。

AIによる推測だけで語義・用法・文法規則を確定しない。

個々の例だけから規則を一般化せず、複数の用例や出現傾向を確認する。

「文法的に可能であること」と「出版物で実際によく使われていること」を区別する。

日本語への訳語だけを覚える教材ではなく、カンボジア語の語・表現・構文が実際にどのような文脈と構造で使われているかを理解できる教材を目指す。

分析によって新しい知見が得られた場合は、Language Inventory、学習体系、教科書、Ankiの内容を必要に応じて更新する。

## 教材の試作

『いつまでも幸せに暮らせます』の日本語版・カンボジア語版のレッスン1〜3を基に、語彙・文法を初歩から学ぶ人向けの[教材の試作](pilot/README.md)を作成している。

[教科書の第1課](pilot/textbook/01-have-advice.md)、出典付きのLanguage Inventory、Anki用TSVを含む。分析の根拠と未確認の範囲については、[試作の分析メモ](pilot/analysis.md)を参照する。
