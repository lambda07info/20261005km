## Language Inventory

Language Inventoryは、単なる学習項目の一覧ではなく、教材全体の基礎となる中核データとして設計する。

教科書とAnkiは、それぞれ独立して内容を考えるのではなく、Language Inventoryに整理された分析結果を共通の基礎として作成する。

また、1つの項目を1つの分類に固定しない。
例えば、ある語は「機能語」であると同時に、特定の「構文」を形成する要素でもあり得る。
そのため、単純な分類よりも、各項目が複数の属性を持てる形で整理する。

### Language Inventoryの主な構成

#### 1. Lexicon

語彙に関する情報を整理する。

- 単語
- 複数語からなる表現
- チャンク
- コロケーション
- 頻出する語の組み合わせ

#### 2. Grammar

文法的な働きを持つ要素を整理する。

- 機能語
- 文法的意味
- 文法的な用法
- 否定
- 時制・相
- モダリティ
- その他の文法機能

#### 3. Construction System

カンボジア語で文をどのように組み立てるかを体系的に整理する。

主な対象：

- 基本的な節の型
- 名詞句の型
- 動詞句の型
- 修飾構造
- 節の拡張
- 節と節の接続
- 語・句・節の並び方
- 各位置に置くことができる要素
- 構文同士の組み合わせ
- 省略可能な要素
- 語順変化
- 語順変化による意味や情報構造の違い

個々の文法項目だけでなく、語・句・節がどのような規則で組み合わされて文を構成するかを明らかにし、カンボジア語の「文の組み立て方」を体系として整理する。

#### 4. Discourse

文より大きな単位での言語使用を整理する。

- 文をつなぐ表現
- 理由
- 結果
- 対比
- 条件
- 説明
- 言い換え
- 列挙
- 結論
- 段落や文章の展開パターン

#### 5. Corpus Evidence

各学習項目について、出版物中の根拠を記録する。

- 出現頻度
- 出現する出版物
- 出現する文脈
- 共起する語や表現
- 実際の用例
- 出典
- 類似する用例
- 用法の分布

出版物で確認できた事実と、そこから導いた一般化は区別して記録する。

例えば、

- Observation：出版物中で実際に確認された用例・傾向
- Rule：複数の用例から導いた文法・構文上の一般化

として分ける。

また、必要に応じて次の情報も持たせる。

- evidence_count
- confidence
- generalization_level

これにより、1つの用例だけから過度に一般化することを防ぐ。

#### 6. Pedagogy

教材化のための情報を整理する。

- 学習上の重要度
- 難易度
- 前提となる学習項目
- 関連する学習項目
- 学習順序
- 出版物読解への重要度
- 文生成への重要度
- 教科書のどこで扱うか
- Ankiでどのように扱うか

## Language Itemの基本データ

Language Inventoryの各項目には、必要に応じて次のような情報を持たせる。

- ID
- 表記
- 項目タイプ
- 意味
- 機能
- 構造
- 構文パターン
- スロット
- 各スロットに入れられる要素
- 文中での位置
- 使用上の制約
- 組み合わせ可能な構文
- 省略可能な要素
- 語順変化
- 共起語
- 出現頻度
- 出現分布
- 使用文脈
- 難易度
- 前提項目
- 関連項目
- JW文脈タグ
- 実例
- 出典
- 教科書での扱い
- Ankiでの扱い
- 根拠数
- 信頼度
- 一般化のレベル

## 構文データの例

例えば、ある表現について次のように整理する。

```text
form:
ដើម្បី

type:
function_word
construction

function:
目的

pattern:
ដើម្បី + VP

slots:
VP = 動詞句

position:
主節の後
文頭

combinations:
S + V + ដើម្បី + VP
ដើម្បី + VP, S + V

constraints:
後続要素は目的となる動作を表す

related_items:
ដើម្បីឲ្យ + Clause

examples:
出版物中の実例

frequency:
出現回数

sources:
出典
````

また、関連する構文は別項目として整理する。

```text
form:
ដើម្បីឲ្យ

type:
construction

function:
目的

pattern:
ដើម្បីឲ្យ + Clause

slots:
Clause = 節

related_items:
ដើម្បី + VP

examples:
出版物中の実例

frequency:
出現回数

sources:
出典
```

このように整理することで、

* 特定の意味を表す構文を一覧化する
* 後ろに節を取る構文だけを抽出する
* 特定の位置に現れる構文を調べる
* 組み合わせ可能な構文を調べる

といった分析が可能になる。

## 教材との関係

Language Inventoryは、次の3つの役割を兼ねる。

1. 出版物の分析結果を保存するデータベース
2. カンボジア語の文法・構文・文生成ルールを整理する仕様書
3. 教科書とAnkiを作成するための共通データ源

基本的な流れは次の通りとする。

JW出版物
→ コーパス化
→ 言語分析
→ Language Inventory
→ 学習順序設計
→ 教科書
→ Anki
→ 検証・改善

教材作成後に新しい分析結果が得られた場合は、まずLanguage Inventoryを更新し、その変更が学習順序、教科書、Ankiに与える影響を確認した上で反映する。
